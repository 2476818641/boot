# 🚀 JCG Q30 Pro (ImmortalWrt 25.12) 宿舍战神版 刷机指南

> **⚠️ 核心避坑警告：**
> 本教程专为跨大版本升级（从老版本升级到 25.12 全新架构）设计。
> **千万不要刷入解压包里的 `bl31-uboot.fip` 文件！** 否则你将失去 237 版不死 U-Boot 的“网页救砖界面”，以后路由器出问题只能拆机用线刷！
> **我们只需利用内存系统作为“跳板”，完美保留 Web 救砖功能并完成底层分区重构！**

## 🔧 准备工作
* **确认前提**：确保你的 JCG Q30 Pro 已经刷入了 **237 版（或 Hanwckf 版）带有 Web 网页界面的不死 U-Boot**。
* **准备网线**：一根网线，连接电脑和路由器的 **LAN 口**。

---

## 🛠️ 详细刷机步骤

### 第 1 步：从 GitHub 下载固件并解压
1. 访问本项目的 **GitHub Releases** 页面。
2. 下载对应机型的完整压缩包（例如：`ImmortalWrt-jcg_q30-pro-Full-xxxx.zip`）。
3. 将 ZIP 压缩包解压到电脑桌面上。
4. 解压后，你只需要认准**这两个文件**（其他的不用管）：
   * 🪂 **跳板急救包**：`...-initramfs-recovery.itb`
   * 📦 **正式系统包**：`...-squashfs-sysupgrade.itb`

### 第 2 步：进入不死 U-Boot 刷入“跳板”系统
1. 拔掉路由器的电源。
2. 找根牙签，按住路由器背后的 **Reset (复位) 键不放**。
3. 插上电源，等待 **10~15 秒** 后松开 Reset 键。
4. 将电脑网卡的 IPv4 地址手动固定为 `192.168.1.2`（子网掩码 `255.255.255.0`）。
5. 打开浏览器，访问 `192.168.1.1`，进入不死 U-Boot 网页界面。
6. 在“更新固件”页面，选择刚刚解压出来的 **🪂 跳板急救包（带有 `initramfs-recovery` 字样的文件）**。
7. 点击更新，等待路由器自动重启。

### 第 3 步：进入临时系统（跳板环境）
1. 等待路由器重启完毕（大约 1~2 分钟）。
2. 将电脑网卡的 IP 地址改回 **“自动获得 IP 地址 (DHCP)”**。
3. 浏览器重新访问 `192.168.1.1`（默认无密码）。
4. **注意**：此时你已经进入了 25.12 版本的 LuCI 网页后台！但这只是一个运行在内存里的**临时系统**，断电就会消失。它的唯一任务就是帮你刷入正式版，**千万别在这里做任何设置或装插件**。

### 第 4 步：在临时系统中刷入“正式版”固件
1. 在网页左侧菜单中，依次点击 **系统 (System) -> 备份/升级 (Backup / Flash Firmware)**。
2. 页面往下拉，找到 **刷写新的固件 (Flash new firmware image)**。
3. 点击上传按钮，选择解压出来的 **📦 正式系统包（带有 `squashfs-sysupgrade` 字样的文件）**。
4. **⚠️ 极其重要：务必取消勾选“保留配置 (Keep settings)”！** 
   *(因为老版本和新版底层的架构完全不同，保留配置 100% 会变砖)*
5. 点击 **刷入 (Flash)**，并确认执行。
